# Armani Interiors — Website

Updated image audit and homepage refinement.

## Image audit
The supplied ZIP was rescanned image-by-image. Four supplied JPGs were removed from the website asset set because they contained visible third-party UI/watermarks or branding:

- IMG-20261007-WA0000.jpg — screenshot/UI elements visible
- IMG-20261007-WA0007.jpg — visible Nice Home branding
- IMG-20261007-WA0010.jpg — visible social-media UI
- IMG-20261007-WA0011.jpg — visible FEMAGA branding/watermark

The site no longer uses those files and does not attempt to erase or reconstruct their watermarks.

The remaining supplied imagery is used selectively and mainly in smaller/editorial positions where its resolution is appropriate. The homepage hero and several replacement visual positions now use high-resolution free-to-use Unsplash imagery rather than stretching weak or watermarked source images.

## Homepage changes
- More image-led and visually full.
- Reduced copy on the homepage.
- Expanded residential, coastal/ocean-view, wall-panel and workspace imagery.
- Added dedicated coastal/ocean-view visual section.
- Added high-resolution panel and workspace references.
- Kept detailed explanatory content primarily on About and Services.
- Image captions were rewritten to match what each image actually depicts.

## Integrity
Mood-board imagery is presented as design and material inspiration; it is not represented as verified Armani Interiors project work.

## External image references
High-resolution replacement imagery is sourced from free-to-use Unsplash photo pages and is used for visual reference rather than claimed client project work.


Mood Board revision — October 2026
----------------------------------
The Mood Boards were rebuilt as 15 original single-image material/sample-board studies. The visual direction was reviewed against the client-provided Unsplash references: green material arrangements, textured sample compositions, neutral sample boards, blue/white material arrangements, wood-and-stone samples, and grey textured material collections. The supplied references are used as visual direction; the board images in this build are original compositions rather than copied reference photographs.

Each board contains one image, a concise image-matched description, and a visual colour strip made from swatches only. No colour-name labels are displayed.
